# J.A.R.V.I.S. MARK LVI — EASY INSTALLATION & USER GUIDE FOR SIR 🚀

Welcome, Sir! This guide makes installing and using your personal **J.A.R.V.I.S. MARK LVI** assistant completely effortless on any Windows 10 or 11 computer.

---

## ⚡ Method 1: One-Click Installer (Easiest)

1. Download **`JARVIS_Mark_LVI_Setup.exe`**.
2. Double-click the file to run the Setup Wizard.
3. Follow the on-screen prompts:
   - Choose your preferred installation folder (defaults to `C:\Program Files\JARVIS Mark LVI` or your User folder).
   - Check **Create Desktop Shortcut** and **Start Menu Shortcut**.
4. Click **Finish**.
5. Double-click the **J.A.R.V.I.S. Mark-LVI** icon on your Desktop.
   - Your web browser will automatically open to `http://127.0.0.1:8000/app`.
   - Your assistant is ready to converse in Hindi, Hinglish, or English!

---

## 📦 Method 2: Portable ZIP (No Installation Required)

1. Download **`JARVIS_Mark_LVI_Windows_x64_Portable.zip`**.
2. Right-click the `.zip` file and select **Extract All...** to any folder (e.g. `C:\JARVIS` or `D:\JARVIS`).
3. Open the extracted folder and double-click:
   - **`install_jarvis.bat`** (first-run setup to verify audio devices and generate shortcuts).
4. Launch J.A.R.V.I.S. anytime by double-clicking:
   - **`launch_jarvis.bat`** (main application & web dashboard).
   - **`launch_floating_companion.bat`** (lightweight floating desktop widget).

## 💻 Autonomous Computer-Use Agent (PC Automation)

In the **PC Automation** view on your dashboard:
1. Type any goal or click a Preset chip:
   - 🚀 **Launch VS Code**
   - 📊 **Capture System CPU and RAM Status**
   - 🔍 **Search Workspace Files**
   - 🌐 **Open GitHub Repository**
   - 📝 **Launch Notepad**
2. Click **▶ Execute Goal**.
3. Watch the real-time **Plan → Act → Observe → Verify** progress bar.
4. **Safety Confirmation Gate:** High-consequence actions (e.g. file deletion, reboot) will pause and display an explicit **Authorize (CONFIRM)** prompt.
5. **Emergency Stop:** A prominent red **🛑 STOP Execution** button immediately halts running operations.

- **Clean Stop:** Double-click **`stop_jarvis.bat`** to stop background services safely without affecting your memories, settings, or files.
